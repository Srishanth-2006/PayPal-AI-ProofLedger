# Demo Recording Scripts

Automated Playwright walkthrough scripts used to record the ProofLedger hackathon demonstration video:

- `record_demo_master_extended.py`: Comprehensive 2-minute 12-second automated walkthrough covering both happy path (PASS -> auto-capture) and edge path (FAIL -> auto-void).
- `record_demo_master.py`: Standard 1-minute 45-second punchy master walkthrough.
